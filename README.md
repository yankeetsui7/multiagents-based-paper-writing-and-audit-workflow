# 长期论文科研 AI 协作系统

本系统由研究者、持续工作的执行 Agent、无跨会话记忆的独立审计 Agent、最小核验包和版本化研究工作区组成。**Project State System 是共享工作区中的状态接续层，不是整个协作系统。**它帮助执行体跨会话恢复进度与决策理由，同时让审计体保持独立判断。

## 系统架构

```text
长期论文科研 AI 协作系统
├── 研究者：目标、标准、争议裁决、成果采用
├── 执行 Agent：计划、实验、分析、写作、整改
├── 独立审计 Agent（无跨会话记忆）
│   ├── 每周中段审计：增量、遗留问题、累积一致性
│   └── 终段审计：完整成果、证据链、可复现性
├── 最小核验包：审计范围、固定版本、证据位置、评价标准
└── 共享且版本化的研究工作区
    ├── 论文、数据、代码、实验结果
    ├── 实验记录、历史审计报告
    └── Project State System
        ├── STATE：进度、阻碍、下一步
        ├── DECISIONS：重大选择及可核查的理由
        └── AUDIT_ISSUES：未关闭问题及复审状态
```

## 技术路线

1. **双 Agent 分工**：执行体生产研究成果，审计体独立验证，研究者作最终决定。
2. **版本化研究工作区**：论文、代码、数据、实验配置和结果保留确定版本与对应关系。
3. **轻量项目状态层**：`STATE.md` 写进度、阻碍和下一步；`DECISIONS.md` 记录重大选择及理由；`AUDIT_ISSUES.md` 跟踪未关闭问题；`EVIDENCE.md` 索引原始依据。执行体仅在重要节点顺手更新。
4. **独立核验**：审计体先依据固定版本、原始证据和标准形成判断，再查历史问题和决策。每周中段审计与项目终段审计使用不同审查范围。
5. **最小核验包交接**：提交范围、关键产物、固定版本、证据位置、评价标准和已知限制。具体要求见 [BOUNDARIES.md](BOUNDARIES.md)。

## 一轮工作流

完整的角色权限、Preview、每周审计、终审和额度控制见 [协作协议 V1.0](WORKFLOW.md)。新实验方案在人工 Preview 前增加 [预实验审查门控](EXPERIMENT_GATE.md)；[V1.2 Hook 与启动器示例](examples/executor/v1.2/research-project/)提供可测试的命令入口检查。[已通过审查的门控实践](PASSED_GATE_CASE.md)记录一次绑定计划与 Manifest 哈希的独立 PASS 和离线复现，以及仍未解决的权限边界。Codex Desktop 与 DeepSeek Harness 的分阶段接入见 [部署路线](DEPLOYMENT.md)；DeepSeek Harness 审计端的可运行实现（两个运行时插件、`audit` / `audit-headless` 专用 profile、启动脚本与交接包模板）见 [implementations/dsh-audit-local-minimal/](implementations/dsh-audit-local-minimal/)。

```text
研究者设定研究目标、阶段任务与验收标准
  → 执行 Agent 从项目状态恢复进度，开展实验、分析与写作
  → 保存可核查产物；重大变更先预览并记录决策理由
  → 到达审计节点：固定版本并提交最小核验包
  → 审计 Agent 独立初审，再复核历史问题与决策
  → 登记缺陷；执行体整改；审计体核验关闭
  → 研究者裁决分歧，更新已确认状态与下一步
  → 下一周期或终段审计
```

中段审计按周运行；终段审计在拟采用完整成果时运行，并可在重大整改后复审。终审结论为 `Accepted`、`Revision Required` 或 `Rejected`。`Accepted` 仅表示通过本项目的内部标准，不代表期刊录用。

## 从模板开始

复制 `templates/` 到自己的**私有研究工作区**。先填写 `PROJECT.md` 和 `STATE.md`；发生重大决策时更新 `DECISIONS.md`，产生核心主张时更新 `EVIDENCE.md`，收到审计缺陷时更新 `AUDIT_ISSUES.md`。每轮审计才填写一次 `HANDOFF.md`。公开仓库只维护流程与空白模板；研究资料留在私有工作区。

## 设计来源

本设计根据用户提供的《逆向解析协作系统》对话记录提炼：在已有执行体、无记忆审计体和最小交接包的基础上，引入低成本的项目状态接续机制，形成完整的科研协作工作流。本仓库是该设想的流程化整理，未声称经过实证评估。
